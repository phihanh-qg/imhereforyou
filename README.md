## Bối Cảnh và Mục Tiêu Dự Án

Trong nhịp sống hiện đại, sự xa cách địa lý và guồng quay công việc khiến con cái khó có thể thăm hỏi bố mẹ mỗi ngày. Ngược lại, người lớn tuổi thường có tâm lý sợ làm phiền con cái, giấu đi nỗi buồn, mệt mỏi hay cô đơn.

**Con Có Ở Đây (I'm Here For You)** ra đời với mục tiêu:
- Đơn giản hóa tối đa việc giữ liên lạc hàng ngày cho người lớn tuổi.
- Xóa bỏ rào cản thao tác công nghệ phức tạp bằng giao diện công thái học thân thiện.
- Cung cấp góc nhìn tâm lý tinh tế từ Google Gemini AI, giúp người trẻ hiểu được tâm tư ngầm ẩn của cha mẹ để quan tâm đúng lúc, đúng cách.

---

## Tính Năng Nổi Bật

### 1. Check-in Một Chạm (One-Touch Check-in)
- Thiết kế nút bấm kích thước lớn, màu sắc tương phản rõ ràng, tối ưu cho mắt và thao tác của người cao tuổi.
- Bố mẹ chỉ cần một chạm để thông báo tình trạng an toàn ("Bố mẹ đã dậy", "Đang ăn cơm", "Chuẩn bị nghỉ ngơi") mà không cần gõ bàn phím.

### 2. Ghi Nhận Tâm Trạng Hàng Ngày (Mood Tracking)
- Biểu tượng cảm xúc trực quan phản ánh nhanh trạng thái tinh thần (Vui vẻ, Bình yên, Hơi mệt, Lo lắng...).
- Lịch sử tâm trạng được lưu trữ trực quan giúp gia đình theo dõi diễn biến sức khỏe tinh thần dài hạn.

### 3. Tin Nhắn Thoại và Nhận Diện Giọng Nói (Voice Messaging)
- Hỗ trợ ghi âm lời nhắn thoại trực tiếp ngay trên trình duyệt.
- Tích hợp công nghệ nhận diện giọng nói đa phương thức của Gemini để phiên âm văn bản tự động, giúp con cái dễ dàng đọc lại khi đang họp hoặc ở nơi ồn ào.

### 4. Trợ Lý AI Thấu Cảm Gia Đình (Gemini Empathy Insights)
- Phân tích chuỗi dữ liệu check-in, sắc thái tâm trạng và lời nhắn thoại trong 7-14 ngày gần nhất.
- Đưa ra nhận xét khách quan về biến động cảm xúc của phụ huynh và gợi ý những câu mở đầu cuộc gọi ấm áp, tinh tế dành cho con cái.

### 5. Báo Cáo Tổng Kết Tuần (Weekly Summary)
- Tự động tổng hợp tuần suất kết nối, những ngày bị gián đoạn và điểm sáng tương tác trong tuần.
- Giúp người con bận rộn nắm bắt trọn vẹn bức tranh cảm xúc của cha mẹ trong 1 phút đọc.

### 6. Bảng Điều Khiển Kép (Dual Dashboard)
- **Giao diện Bố Mẹ (Parent View)**: Đơn giản, phông chữ lớn, chỉ tập trung vào việc check-in và gửi lời nhắn.
- **Giao diện Con Cái (Child View)**: Đầy đủ biểu đồ phân tích, thông báo tức thì và các đề xuất từ trợ lý AI.

## Kiến Trúc và Công Nghệ Sử Dụng

### Frontend
- **React 19**: Tận dụng các tính năng mới nhất về hiệu năng rendering và quản lý trạng thái.
- **TypeScript**: Đảm bảo an toàn kiểu dữ liệu và kiến trúc module mở rộng.
- **TailwindCSS v4**: Hệ thống thiết kế hiện đại, tùy biến linh hoạt theo kích thước màn hình.
- **Motion**: Hiệu ứng chuyển cảnh nhẹ nhàng, tạo cảm giác mượt mà và tự nhiên.
- **Lucide React**: Thư viện biểu tượng đồng nhất, tối giản.

### Backend & AI Engine
- **Express.js (Node.js)**: Máy chủ API xử lý xác thực, định tuyến và tích hợp nghiệp vụ.
- **Google Gen AI SDK (`@google/genai`)**:
  - Mô hình chính: `gemini-3.7-flash` xử lý phân tích ngữ cảnh sâu và xuất dữ liệu JSON có cấu trúc.
  - Cơ chế tự phục hồi (Resilient Fallback): Tự động chuyển tiếp linh hoạt qua `gemini-3.1-flash-lite` hoặc `gemini-flash-latest` khi gặp lỗi tài nguyên hoặc nghẽn mạng tạm thời.
- **Firebase**: Quản trị dữ liệu đồng bộ thời gian thực giữa hai giao diện người dùng.

## Hướng Dẫn Cài Đặt và Khởi Chạy

### Yêu Cầu Hệ Thống
- [Node.js](https://nodejs.org/) phiên bản 18.x hoặc mới hơn.
- Trình quản lý gói `npm` hoặc `yarn`.
- Khóa API của Google Gemini ([Google AI Studio](https://aistudio.google.com/)).

### Các Bước Cài Đặt

1. **Clone repository về máy**:
   ```bash
   git clone https://github.com/phihanh-qg/imhereforyou.git
   cd imhereforyou
   ```

2. **Cài đặt các gói phụ thuộc**:
   ```bash
   npm install
   ```

3. **Thiết lập biến môi trường**:
   Tạo tệp `.env` tại thư mục gốc của dự án:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   PORT=3000
   ```

4. **Khởi chạy ứng dụng ở môi trường phát triển**:
   ```bash
   npm run dev
   ```

5. Mở trình duyệt và truy cập: `http://localhost:3000`.

### Biên Dịch Sản Phẩm (Production Build)
```bash
npm run build
npm start
```
